# Dallae Web

달래(Dallae) 안드로이드 앱의 핵심 루프(목표 → 타이머 → 정원)를 웹으로 구현한 React 앱입니다.

- 목표(씨앗) 만들기, 타이머로 시간 투자, 다 자라면 정원에 꽃으로 배치
- 50종 한국 자생화 도감
- 기존 [Dallae 앱](https://github.com/mooniknet/dallae)과 **같은 Supabase 계정/데이터**를 공유합니다 (아이디/비밀번호 로그인 방식 동일)
- 계정당 백업 데이터는 단일 JSON으로 저장되며, 앱이 쓰지 않는 필드(중첩 스킬맵, 친구, 메시지 등)는 그대로 보존한 채 병합하여 저장합니다

## 개발

```bash
npm install
npm run dev
```

## 빌드

```bash
npm run build
```

`dist/`를 정적 호스팅(GitHub Pages 등)에 배포하면 됩니다.

## 범위

이 웹 버전은 "핵심 루프"만 구현합니다: 중첩 스킬트리 편집, 친구 정원, 최근 업데이트 피드, 관리자 기능은 포함하지 않습니다.
